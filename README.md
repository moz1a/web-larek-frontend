# Проектная работа "Веб-ларек"

Данный сайт предназначен для совершения онлайн покупок для разработчиков.
На сайте присутствует каталог товаров, подробная информация для товаров, функционал корзины и совершения заказов.

Стек: HTML, SCSS, TS, Webpack

Структура проекта:

- src/ — исходные файлы проекта
- src/components/ — папка с JS компонентами
- src/components/base/ — папка с базовым кодом

Важные файлы:

- src/pages/index.html — HTML-файл главной страницы
- src/types/index.ts — файл с типами
- src/index.ts — точка входа приложения
- src/scss/styles.scss — корневой файл стилей
- src/utils/constants.ts — файл с константами
- src/utils/utils.ts — файл с утилитами

## Установка и запуск
npm install
npm run start



## Сборка
npm run build


# Описание базовых классов, их предназначение и функции.

Api - класс, описывающий работу с сервером
Функции:
предоставляет функционал методов GET | POST;
отвечает за отправление запросов на сервер;
отвечает за обработку ответов сервера.

EventEmitter - класс, отвечающий за обработку событий
Функции:
on - предоставляет функционал подписки на события;
off - предоставляет функционал отписки от события;
onAll - слушает все события;
offAll - сбрасывает все обработчики;
emit - инициирует события с данными;
trigger - создает коллбек триггер, генерирующий событие при вызове.

# Описание архитектурного паттерна MVC.
Model — отвечает за данные и бизнес-логику.
View — отвечает за отображение данных пользователю.
Controller — принимает ввод от пользователя, изменяет Model и обновляет View.

# Model
CartModel - класс, отвечающий за добавление\удаление продуктов в корзину.
OrderModel - класс, отвечающй за выбор способа оплаты, адреса доставки.
PersonalDataModel - класс, отвечающий за указание персональных данных покупателя.

# View
CatalogView - класс, отвечающий за представление каталога продуктов на главном экране.
ProductView - класс, отвечающий за представление модального окна с подробной информацией о товаре.
ModalView - базовый класс обертки модальных окон
CartView - класс, отвечающий за представление модального окна корзины.
OrderView - класс, отвечающий за представление модального окна деталей заказа.
PersonalDataView - класс, отвечающий за представление модального окна персональных данных покупателя.
BuyView - класс, отвечающий за представление модального окна совершенной покупки.

# Controller
CartController - класс, отвечающий за логику добавления и удаления продуктов в корзину.
OrderController - класс, отвечающий за логику добавления деталей заказа.
BuyController - класс, отвечающий за отправление заказа.
